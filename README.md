# IC · 无限画布扩展下载

这是 IC 无限画布扩展的公开分发仓库，用于提供扩展安装包和版本说明。

## 下载

请到 [Releases](https://github.com/Anz2026/infinite-canvas-extension-releases/releases) 下载正式版本的 ic-extension-版本.zip。

尚未发布安装包时，Releases 列表为空。GitHub 自动提供的 Source code 归档不是扩展安装包。

## 安装与更新

首次安装：解压扩展 ZIP，在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载包含 manifest.json 的解压目录。

更新：等待当前任务结束，关闭画布页，备份原扩展目录，将新版文件替换到原加载目录，再重新加载原扩展。请保留同一浏览器配置和扩展 ID，不卸载扩展或清理浏览器数据。重要画布建议先导出备份。

## 仓库用途

本仓库仅保存使用说明，以及通过 GitHub Releases 发布的安装包和更新说明。开发源码、开发记录、开发配置与访问凭证不上传到本仓库。
